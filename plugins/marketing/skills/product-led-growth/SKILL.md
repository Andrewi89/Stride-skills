# Product-led growth

The product does most of the acquiring, converting and expanding. A person tries it, gets value fast, and the product pulls them toward paying and inviting others. Positioning and channel choice still come first: see `marketing`.

## Core ideas

- **Time to value:** how long from first visit to the moment a person gets something real. Shorten it. Every extra step before value loses people.
- **Activation event:** the one early action that best predicts someone sticking around (for example, "sent a first invoice"). Find it in the data. Design onboarding to reach that event, nothing else.
- **Product-qualified lead (PQL):** a user whose in-product behaviour shows buying intent, so sales or an upgrade prompt targets them, instead of chasing sign-ups blindly.
- **Growth loop:** output of one user becomes input for the next (shared reports, invites, public pages, integrations). A loop compounds. A funnel only converts what you pour in.

## Free trial or freemium?

| Choose | When |
|---|---|
| Freemium | Serving a free user costs almost nothing, value shows quickly, and usage spreads between people. |
| Free trial | Value needs setup or real data, costs per user are meaningful, or the buyer needs to evaluate before committing. |
| Reverse trial | You have a free tier and want new users to see paid features first. Everyone starts on paid for a set time (often 14 days), then drops to free. |
| Neither (demo or pilot) | High-touch, regulated, hardware-installed or long-cycle products. |

Put the paywall where value is already proven. Gate depth and scale (more projects, more seats, advanced features), and leave the first useful result free.

## Onboarding

1. Show the quickest route to the activation event.
2. Use sample data or templates so the first screen is never empty.
3. Remove every field you don't need yet.
4. Prompt for the next step only after the first success.

Write interface words with `design-copy`.

## Measure

- Sign-up to activation rate and time to activation.
- Activation to paid conversion, and time to first payment.
- Retention by week for activated versus non-activated users.
- Expansion: seats, usage or plan upgrades per account.
- Viral or loop rate: new users per existing user.

Pick one number per stage. Compare cohorts, not totals. Treat public benchmarks as dated.

## When PLG is the wrong fit

- Products installed on site by trained professionals, or sold through quotes and contracts. A hybrid works: a free tool or calculator that earns trust and leads, with people handling the sale.
- Heavily regulated or compliance-led purchases with long procurement.
- Very large, custom or integration-heavy deals.

In those cases use the product for lead generation and proof, and keep a human step for the sale.

## Pitfalls

- Free tier too generous, so nobody has a reason to pay.
- Paywall too early, before value is clear.
- Measuring sign-ups instead of activation.
- Copying a famous company's model without checking cost per user and buyer type.
- Onboarding that explains the product when it should let people use it.
